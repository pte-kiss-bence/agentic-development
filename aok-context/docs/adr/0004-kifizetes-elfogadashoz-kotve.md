# A kifizetés a tárgyfelelősi elfogadáshoz kötött

Csak az **elfogadott** (tárgyfelelősi token vagy admin override) órák díja **fizetendő**; a nem elfogadott — lezáráskor „átcsúszott" — órák díja **függő/visszatartott**, a fizetendőtől elkülönítve. Az elfogadás így nemcsak egy ellenőrző checkpoint, hanem tényleges **kifizetési kapu**.

## Considered Options

- *„Fizess mindent, csak jelöld az el nem fogadottat"* — **elvetve**. A tárgyfelelősi igazolást szándékosan kifizetési kapuvá tettük, tükrözve a kiváltott papír-aláírásos folyamatot (előbb igazolás, utána pénz).

## Consequences

- Ha a tárgyfelelős nem reagál, az **admin override** felszabadíthatja a díjat. A függő díj a lezáráskori PDF-en és a táblázatban külön tételként jelenik meg.
